# MotiBuddy

MotiBuddy 是一款将任务管理、日历、专注计时与虚拟宠物陪伴结合的 Windows 桌面应用。项目以可靠的本地数据保存和连贯的桌面交互为核心，支持中文与英文界面。

## 功能

- **任务清单**：截止时间、时间段、耗时排序、批量录入、桌面提醒及日程冲突确认。
- **独立日历**：月历与日/周日程视图，展示时间段任务，支持查看和修改安排。
- **数据统计**：完成趋势、专注累计、历史周报，与日历分别组织。
- **宠物陪伴**：领养与成长、六种个性、喂食和互动、桌面小组件。
- **宠物助手**：日常对话、今日计划、图片录入、任务推荐、每周复盘、情绪陪伴、定时任务与可搜索的对话历史。
- **专注空间**：可调整的专注/休息循环、四首授权音乐、累计记录和完成反馈。
- **手账与纪念日**：可编辑文字、照片、贴纸和手绘。情绪对话经过确认后才能写入手账。
- **天气**：默认北京；经授权定位后显示城市名称。提供小时预报、空气质量预报、体感温度、湿度、紫外线、风、气压、能见度和日出日落。

## 界面设计

界面延续桌面小组件的视觉语言：半透明白色卡片、轻微背景模糊、圆角、珊瑚红与青绿色点缀，以及带描边和小偏移阴影的按钮。主内容强调清晰阅读，交互控件保留轻松的玩具感。

## 技术栈

React 18、TypeScript、Vite、Tauri 1、Rust、Recharts。Node.js 24 用于开发工具、测试及可选 AI 服务。业务数据按账户保存，写入使用版本校验、原子替换和可恢复记录。

## 开发环境

- Windows 10/11
- Node.js 24
- Rust 稳定工具链、Visual Studio C++ Build Tools、WebView2 Runtime

```powershell
npm install
npm run tauri:dev
```

仅调试网页界面可以运行 `npm run dev`；系统通知、小组件、系统语音识别及原生数据写入需要桌面环境。

## 构建与检查

```powershell
npm run check
npm run test:rust
npm run tauri:build
```

独立浏览器回归使用测试账户及模拟原生桥接，不读取真实账户数据：

```powershell
node test_scripts/localization_smoke.mjs
```

针对天气、日历及助手交互的回归：

```powershell
$env:WORKSPACE_V5='1'
node test_scripts/localization_smoke.mjs
```

## AI 集成

AI 能力是可选模块。配置方式与开发入口见 [服务端说明](server/README.md)。供应商凭据只允许保留在不受版本控制的服务端环境中，不写入前端、桌面程序或发布资源。仓库提供配置模板，不提供可供其他用户使用的生产凭据。

桌面提醒和定时任务需要应用运行或留在托盘；完全退出应用及关机后不执行。天气和 AI 功能需要相应网络服务可用。定位需要授权，未授权时使用北京；定位数据不会进入 AI 对话。
