# 本机 AI 网关（第一批开发模式）

需要 Node.js 24，与主项目版本一致。无新增服务端依赖，复用 Zod 契约。

## EXE 验收：一键启动

在项目根目录双击 `Start-MotiBuddy-AI.cmd`（也可运行 `npm run agent:desktop`）。入口会检查服务状态；没有服务时在后台启动，等待就绪后打开 `MotiBuddy-Verify-companion.exe`，已有可用服务则复用，不会重复启动。必须保留本项目目录、Node.js 24、已安装的依赖和本机私有配置；该入口仅供本机验收，不能把私有配置打包交付给其他用户。

AI 服务在后台保持运行，关闭应用后仍可供下次使用，系统重启后再次使用这个入口即可。若端口被其他服务或旧版网关占用，入口会报错并停止，不会自动结束其他进程。修改私有配置后，需先关闭旧网关进程，再启动新版。

仅双击 EXE 不会启动独立服务。如果应用已经打开，可以运行 `node scripts/start-agent-desktop.mjs --service-only`，随后回到应用重新发送。服务就绪检查不调用模型、不消耗模型费用；没有修改前端或 EXE，也没有把供应商密钥传给桌面进程。

## 开发模式

1. 将 `.env.example` 复制为本目录的 `.env.local`，只在该私有文件设置 DeepSeek 密钥。
2. 首次配置可运行 `node scripts/configure-agent-secret.mjs`：从隐藏的标准输入读取供应商密钥，并自动生成服务端内部凭证。本机配置已经存在时不需要重复执行。服务端内部凭证不需要交给客户端或用户。
3. 项目根目录执行 `npm run agent:server`；另一个终端执行 `npm run tauri:dev`，启动含当前源码的桌面开发版（其启动流程会自动启动 Vite）。首次 Rust 构建会重新生成较大的编译缓存。
4. 进入左侧“宠物助手”，直接发消息或点击“今日计划 / 创建任务”卡片。应用自动建立短期连接，无需填写或复制网关访问凭证。旧网关进程需要先关闭，再用上述命令启动新版。

`POST /api/agent/session` 只向来源白名单中的本机页面签发 10 分钟短期会话，绑定 Origin，限频并限制会话数量。短期令牌只保存在应用内存，退出或账户切换时清除；服务端内部长期凭证和 DeepSeek 密钥均不发送给客户端。不同会话共享模型调用限额，重新连接不能绕过额度。

服务器固定监听 127.0.0.1，仅接受开发页和 Tauri 来源。默认每分钟 10 次、每日 100 次、同时 1 次，额度为当前进程内计数，重启会重置。超时 60 秒；输入和输出均有限长。日志不记录任务、图片或上游正文。失败调用也消耗本地请求次数，供应商费用遵循其实际计费。

本机模式供项目所有者开发验收，不应通过端口转发对外开放，也不应把 `.env.local` 随 EXE 发给用户。公开交付前需独立部署 HTTPS 网关，加入真实用户认证、持久配额及监控；当前本地账号不是服务端可信身份。本批不自动提供公网连接配置。

不在日志、截图、报告或 Git 中展示 `.env.local` 内容。密钥改变后重启网关生效。

## 可选腾讯云播报

在同一私有文件中配置 `TENCENT_TTS_SECRET_ID`、`TENCENT_TTS_SECRET_KEY`；本机已经配置，无需重复输入。`scripts/configure-tts-secret.mjs` 从不回显的标准输入 JSON 读取配置并保留原有服务设置。服务端负责 TC3 签名，前端只提交文本和 girl/boy 音色代号，不接收供应商凭证。

`POST /api/agent/tts` 复用来源与短期会话校验，单次最多 120 个 Unicode 字符，独立限制并发 1、每分钟 60 次、每日 30000 字符（内存计数，重启重置）。模型响应仅在用户点击播报后合成；超长回答客户端分段播放。上游错误正文不返回用户。验证命令 `node --env-file=server/.env.local scripts/verify-companion-v2.mjs` 使用合成文字和实际音色，不记录私有密钥。

当前项目的真实业务存储依赖 Tauri。`npm run dev` 只启动网页开发服务器，不能替代原生存储验收；自动浏览器测试使用隔离的模拟 Tauri 桥和模拟 AI 响应。已单独通过真实自动连接、普通对话、文字、图片及计划请求验证，见 `docs/AGENT_API_VERIFICATION.json`。
