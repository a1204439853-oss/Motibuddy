# MotiBuddy v0.1.0 - Thesis Release

## 🎓 Graduation Thesis Project

This is the initial release of **MotiBuddy**, a gamified intelligent task management application developed as a graduation thesis project.

## ✨ What's Included

### Application
- **MotiBuddy_0.1.0_x64_en-US.msi** - Windows Installer (Recommended)
- **MotiBuddy.exe** - Portable executable

### Features
- 🐾 **Virtual Pet Nurturing**: Four pet types (Cat, Dog, Panda, Bird) with status tracking
- 🎙️ **Voice Input**: Natural language task creation with NLP parsing
- 🖥️ **Desktop Widget**: Always-on-top window for persistent engagement
- 📊 **Task Management**: Priority-based organization with smart sorting
- 🏆 **Achievement System**: Gamified motivation through unlockable achievements

## 📋 System Requirements

- **OS**: Windows 10/11 (64-bit)
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 500MB available space
- **Microphone**: Required for voice input feature (optional)

## 🚀 Installation

### Option 1: MSI Installer (Recommended)
1. Download `MotiBuddy_0.1.0_x64_en-US.msi`
2. Double-click to run the installer
3. Follow the installation wizard
4. Launch from Start Menu or Desktop

### Option 2: Portable Version
1. Download `MotiBuddy.exe`
2. Place in your preferred directory
3. Double-click to run (no installation required)

## 📝 Quick Start Guide

1. **First Launch**: Register a new account or login
2. **Choose Your Pet**: Select from Cat, Dog, Panda, or Bird
3. **Name Your Pet**: Give your companion a unique name
4. **Create Tasks**: 
   - Type manually, or
   - Use voice input by clicking the microphone button
5. **Complete Tasks**: Watch your pet grow happier and level up!

## 🧪 Known Issues

- Voice recognition requires an internet connection
- Desktop widget transparency may vary on different Windows themes
- Pet animations require video codec support
