# 桌面界面与动效设计

MotiBuddy 的桌面界面采用新粗野主义设计：明确的深色描边、不带模糊的偏移阴影、实色色块，以及紧凑的小圆角。信息层级通过布局、字重和留白区分；任务、对话正文和日历网格保留细分隔线，避免重复堆叠外框。

## 视觉系统

- 背景使用暖白与浅米色，主要操作和选中状态使用青绿色，宠物喂食使用珊瑚色，提示使用浅黄色。错误和优先级继续具有明确的语义标签。
- 导航保留三栏布局。未选中项目使用轻量背景，当前模块使用实色、描边和硬阴影；设置固定在导航底部。
- 任务搜索、过滤、表单、助手场景卡片、日历、天气、统计、专注、手账、成就、账户页面及桌面小组件共用设计变量。手账保留正文手写字体，欢迎页保留原有视频。
- 助手保留白色对话区。新对话、历史记录及个性与音色控制继续位于同一工具区域。语音与发送保持相邻圆形按钮。
- 桌面小组件内容使用不透明面板；窗口外部仍保持透明。已有宠物视频、数据与账户状态保持原有行为。
- 导航顶部的头像与时间共用卡片，天气使用两行摘要及详情入口。宠物名称与等级徽标同排，经验值在下方显示；四项状态以图标、名称、进度和数值同排呈现。
- 助手消息按左右头像区分，宠物名称与回复时间显示在气泡上方，用户时间显示在气泡下方。新增消息时间随历史记录保存；没有时间的旧消息继续兼容，不补造时间。
- 导航折叠与设置图标、创建账号、忘记密码和返回登录使用无外框操作样式，并保留键盘焦点反馈。

设计变量与兼容已有组件的规则位于 `src/components/ui/neo-brutalism.css`。两个窗口通过 `desktop.css` 按同一顺序加载样式，防止生产构建拆分资源后改变覆盖顺序。组件通过具名样式类接入，不通过文案或元素位置判断业务状态。

## 动效

| 场景 | 交互反馈 |
| --- | --- |
| 按钮按压 | 约 100 毫秒，沿阴影方向移动 2 像素并收回硬阴影 |
| 模块与消息 | 约 180 毫秒，短距离位移后停止，保持内容清晰 |
| 任务完成 | 保存成功后勾选、划线、收拢描述，短暂显示完成标记；保留重新打开操作 |
| 宠物互动 | 保留现有视频，增加一次约 420 毫秒的轻量回应 |
| 专注与成就 | 有限时长的几何彩带和庆祝反馈，专注计时期间保持安静 |

系统的“减少动态效果”偏好通过实时订阅读取，变更时会停止助手自动轮播和装饰运动；任务保存、状态反馈与操作功能仍然可用。键盘焦点使用清晰的外框，宠物点击区域支持 Enter 和空格。

## 验证

```powershell
npm run check
npm run build:desktop
node test_scripts/localization_smoke.mjs
$env:NEO_ONLY='1'
node test_scripts/localization_smoke.mjs
Remove-Item Env:NEO_ONLY
```

生产资源可在完成构建后使用同一专项检查：设置 `NEO_ONLY=1` 和 `UI_PREVIEW_BUILD=1`，再运行 `localization_smoke.mjs`。它会启动 Vite 预览服务，验证实际打包资源；运行结束后清除这两个环境变量。

专项界面验证覆盖三种桌面宽度、真实指针按压、任务完成与重新打开、对话保留、系统动态偏好实时切换，以及日历、统计、专注、手账和窄屏设置。界面测试使用隔离浏览器和合成账户，不读取桌面应用的现有用户数据。

验证版使用 `tauri.verify.conf.json` 构建，本次验收文件为 `MotiBuddy-Verify-ui-details.exe`。本地启动脚本使用该文件名；构建产物不提交源码仓库。
