# Agent 对话版手动验收

更新：2026-10-16。当前实现普通对话、今日计划、文字/图片任务草稿、草稿保存恢复与原子批量导入。其余场景见待开发计划。本次重点是三栏界面、对话引导与宠物反馈。

## 启动

1. 关闭之前的 MotiBuddy 验收版，在项目根目录双击 `Start-MotiBuddy-AI.cmd`。入口会检查本机服务，必要时在后台启动，等待就绪后打开 `MotiBuddy-Verify-focus.exe`。已有服务时会复用；旧版或其他服务占用端口时会提示，不会强制结束进程。
2. 应用沿用验收版应用标识和数据位置。当前专注版构建信息与哈希见 `FOCUS_BUILD.json`，新增功能验收见 `FOCUS_SPACE.md`；前一版日历／语音记录保留在 `PET_SCHEDULE_BUILD.json`。如需只启动服务，可执行 `node scripts/start-agent-desktop.mjs --service-only`。开发时仍可使用 `npm run agent:server` 并保持终端开启。
3. 登录并点击左侧“宠物助手”，直接发消息；不需要填写、复制或粘贴任何网关凭证。

DeepSeek 密钥仍只在被 Git 忽略、收紧 Windows 访问权限的服务端私有环境文件中。客户端自动申请短期本机会话；密钥和内部长期凭证不会被发送给客户端或打包进 EXE。仅打开 EXE 不会自动启动独立网关，请使用一键入口；服务在后台持续运行，系统重启后需重新启动。入口依赖本项目目录和 Node.js 24，仅供本机验收。

## 界面

- 欢迎、登录页的“中 / 英”与登录按钮并排，无边框、彩色底或阴影；当前语言加粗，切换时表单内容和 URL 保持不变。
- 任务列表正常状态不再显示“任务已保存”；保存中、读取中和失败提示仍然有效。
- 点击助手后，左侧导航和右侧宠物保留，中间切换为对话页，没有助手弹窗。
- 今日计划、创建任务两张卡片位于输入框上方，标题加粗，下方一行简短说明。
- 在 1200×675 和 1600×900 下切换中英文，检查输入框、卡片、回复和滚动区域；长标题不应挤出中间栏。

## 对话与宠物

- 直接说“你好，你能帮我做什么？”，应获得普通对话回答，不需要连接设置表单。
- 点击“今日计划”，应先询问可用时间、精力和偏好。只说“先做紧急任务”时，应继续询问时间，不能悄悄当成 60 分钟。
- 回答“我有 30 分钟，有点累”，推荐任务来自当前未完成列表，总推荐耗时不超过 30 分钟，有原因和第一步。
- 每次发送时，宠物播放与点击互动相同的随机动作，同时显示以下五句之一：
  - 别催别催，脑子正在加热中！
  - 正在翻箱倒柜找答案，等我一下下
  - 稍等哦，我去脑子里抓个小精灵
  - 你的问题我接住啦，马上来~
  - 叮！思考模式启动中
- 英文模式显示对应英文气泡。更高优先级的喂食、庆祝等动作不会被强行打断；互动继续遵循已有的每日规则，不增加任务完成经验。
- Enter 发送，Shift+Enter 换行；中文输入法选词时 Enter 不应误发送。

## 图片和草稿

- 点击“创建任务”，根据对话提示输入想法或添加清晰的 PNG/JPEG/WebP 待办图片。
- 消息中能看到本次图片，回复中有待确认任务草稿。缺失的截止时间建议按当前时间后 24 小时、预计耗时按 30 分钟补全，均明确提示为建议，可点击“修改”调整。
- 在对话中补充日期/要求，可生成更新后的建议；确认前不会直接创建正式任务。
- 修改标题、说明、未来截止时间、优先级和分钟数，勾选要导入的任务。
- 点击保存草稿后，切换任务页再回来应保留编辑；离开主界面再回来，也应恢复已保存草稿。
- 确认录入后应一次出现全部选中任务，重复标题与截止时间的任务会阻止整批导入。
- 已生成结果自动保存；后续手动编辑需要保存草稿。聊天记录只在当前主界面会话中保留，原图不随任务草稿长期保存。

## 异常与隔离

- 网关未启动时应显示连接错误，原任务不变；启动后直接重新发送即可。
- 请求过程中点击“停止”或切换到任务页，迟到回复不得覆盖后续页面或创建任务。
- 保存失败保留草稿；导入未知状态时使用同一批次重试，不能出现半批或重复任务。
- 退出并登录其他账号，不能看到前账号的草稿、聊天或复用其短期连接。
- 浏览器自动测试使用模拟 Tauri 和模拟 AI，真实 API 测试使用合成输入；两者不能代替本次实际 EXE 验收。

本机服务固定监听 127.0.0.1，有来源白名单、自动会话有效期、频率和并发限制。所有短期会话共享调用额度，重启服务后进程额度重置。公开部署仍需真实服务端身份、持久配额与 HTTPS，不能将该本机服务直接暴露到公网。
