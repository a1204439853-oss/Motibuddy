# 宠物、语音与日历行程更新（2026-10-16）

## 已实现

- 宠物助手背景和右侧宠物对话气泡改为纯白。助手消息署名、思考状态使用用户自己的宠物名称。
- 点击宠物使用专门的互动语料库，增加 15 句中英文短句，与原有 5 句共 20 句；连续点击避免重复同一句。原有喂食、玩耍、心情语料继续保留。
- 所有宠物状态界面将“饥饿”改为“饱腹”，饱腹越高状态越好，包括主窗口、侧栏、小组件和恢复选择。新领养宠物显示健康、快乐、饱腹、精力各 70。
- 助手输入框增加语音转文字。Windows 本机识别一次短句，停顿后返回，最长 25 秒；文字先进入输入框，不自动发送或创建任务。取消、换语言、切换页面、退出账户时停止识别并丢弃迟到结果。
- 任务创建、修改支持截止时间与时间段二选一。时间段填写开始和结束时间，结束必须晚于开始，可以跨午夜、多日；任务卡显示起止时间和实际分钟数，搜索旁增加时长升／降序。未设置耗时的任务排在最后；时间段提醒按开始时间提前计算。
- 助手根据对话识别创建意图，并用最多 200 项未完成任务匹配已有待办：明确创建或未匹配的行动目标生成草稿，已匹配的任务给予下一步建议，闲聊保持对话。未提供的截止时间建议为当前时间后 24 小时、预计耗时 30 分钟，优先级普通；建议补全项会显示在待确认信息中。
- 待确认卡片提供“修改”，可调整标题、说明、时间类型、起止时间、优先级与预计耗时。保存草稿包含勾选结果；确认后通过原有原子批量提交同步任务栏，失败仍保留草稿，并沿用同一批次重试以防重复创建。
- 数据统计的散点任务时间线替换为日历行程：周／日视图、前后翻页、回到今天、24 小时网格、当前时间线、顶部截止事项、重叠日程分栏、跨午夜分段、已完成显示开关。点击日程／截止事项可用统一任务表单修改。

## 数据兼容

现有宠物数据的 `hunger` 仍表示原来的饥饿程度；界面饱腹值取 `100 - hunger`，喂食、衰减及历史任务奖励无需破坏性迁移。新宠物内部 `hunger=30`，其余三项为 70。已有宠物不重置为 70。

旧任务未设置 `timingMode` 时仍视为截止任务。新时间段使用 `timingMode=range`、`startAt` 和 `dueDate`（结束时间），避免改变已有到期、完成、提醒与奖励逻辑。前端和 Rust 存储均校验时间顺序，保存后仍按现有业务文件／备份／事务回执机制读取。

## 语音实现和边界

桌面语音使用 Windows 安装的 System.Speech 识别器及听写语法；没有接入收费语音服务，不保存录音文件，不将录音发给 DeepSeek。当前系统已验证中英文识别器及听写语法可初始化；麦克风输入权限、默认设备、环境噪声与实际识别效果仍需人工验收。缺少识别组件或麦克风不可用时会显示提示，原输入保留。本批新语音按钮供 Windows EXE 使用。

实现参考：[Microsoft SpeechRecognitionEngine 文档](https://learn.microsoft.com/en-us/dotnet/api/system.speech.recognition.speechrecognitionengine?view=netframework-4.8)。后台识别限制为主窗口调用，串行占用麦克风，取消按请求 ID 匹配，避免旧页面的取消命令影响新请求。

## 手工验收顺序

1. 退出旧版应用，双击根目录 `Start-MotiBuddy-AI.cmd`，自动检查 AI 服务并启动 `MotiBuddy-Verify-calendar.exe`。沿用 Verify 数据目录，不会清空已有账号。
2. 创建新账户、领养宠物，确认四个数值显示 70。旧账户确认饱腹值为旧饥饿值的反值；喂食后饱腹提高。
3. 点击宠物，确认不同语料和纯白气泡；进入助手，检查消息署名为宠物姓名。
4. 点击“语音输入”，说“帮我创建明天上午九点到十点的阅读任务”，停顿后先检查输入文字，再发送。另测取消、录音时切换页面、麦克风权限关闭及中英切换。
5. 发“帮我创建整理书桌的任务”，确认建议补全提示。点“修改”，切换时间段、改起止时间，确认创建；去任务页检查，重启应用后再次检查。
6. 手动创建跨午夜时间段，尝试结束早于开始，确认被阻止且旧记录保留。用时长升降序检查范围任务按实际长度排序，未知耗时在末尾。
7. 到日历切换周／日、翻页，检查时间块、顶部截止事项、重叠／跨午夜显示，点击修改并确认任务列表同步。

自动验证和构建记录见 `PET_SCHEDULE_BUILD.json`、`AGENT_SCHEDULE_VERIFICATION.json`。浏览器自动验证使用隔离模拟数据和 Tauri 桥，不替代真实麦克风及 EXE 的最终手工验收。
