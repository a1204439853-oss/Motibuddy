# MotiBuddy Agent 待开发与验收计划

更新：2026-10-16。本文先于实现建立；以勾选项和末尾实施记录为准，不将方案当成已完成功能。

## 1. 产品目标与范围

用一个宠物助手入口承载六类能力：今日计划、图片/文字任务录入、真实周复盘、个性化推荐、情绪树洞与图片手账、语音任务操作。所有功能支持中文和英文，并沿用现有黑色边框、硬阴影及青绿色主按钮。

核心模型：DeepSeek 官方 API，`https://api.deepseek.com`，`deepseek-flash`。目前官方文档列出图像理解、JSON Output 和工具调用。模型响应只提供候选内容；程序校验、用户确认与现有账户事务负责最终写入。

## 2. 密钥、数据和交付边界

- DeepSeek 密钥只放在独立服务端的私有环境文件；不得使用 VITE_ 变量，不得写进前端、Rust 二进制、测试夹具、文档或 Git。
- 服务端调用固定的官方 HTTPS 地址，不接受客户端提供的上游地址、模型、提示词角色或任意工具名称。
- 第一批使用仅本机监听的开发网关，独立访问凭证、来源白名单、请求大小、并发、频率、每日调用上限和超时控制；不把本机测试网关宣称为已完成的公网账号后端。
- 应用自动获取 10 分钟短期本机会话，绑定来源并仅保存在内存，退出/切换账户时清除。无需用户复制或输入访问凭证。服务端内部长期凭证与供应商密钥都不传给客户端。不同短期会话共享调用限额；仅适用于本机来源白名单模式，不能作为公网用户认证。
- 公网发布前必须完成真实服务端身份认证、每用户持久额度、HTTPS 部署与监控。当前本地账号 ID 不是可信的服务端身份。
- 请求只包含用户主动选择发送的文字、相关任务及图片。服务端不记录正文、图片、密钥或上游错误原文；不上传密码、邮箱或完整账户文件。
- 任务写入复用现有 BusinessRepository/Tauri 原子保存、会话校验与操作去重。AI 不可直接改变宠物奖励和任务完成状态。
- 图片识别结果、日记和任务描述均作为不可信内容，不获得额外执行权限。
