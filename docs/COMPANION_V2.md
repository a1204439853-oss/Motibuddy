# 陪伴体验与系统提醒改进（2026-10-17）


此版本的功能范围包括：鲜明个性和助手内切换、原生有声桌面提醒、专注纯音乐、紧凑卡片与隐藏滚动条、AI 提示语、腾讯云可选播报、任务清单的今日计划/每日任务、统计周报归档、开始时间加半小时与整批全选、可跳过画像问卷与立即推荐、可编辑手账、导航名称及定时任务最新消息排版。

密钥仅存本机忽略的私有服务配置，不进入前端、手账、构建产物或日志。腾讯云使用官方 TextToVoice 与超自然音色，系统展示名称为“元气女生”“活力男生”。

“待机”按主窗口隐藏/最小化但应用仍在托盘运行实现；真正退出应用或电脑睡眠时没有运行中的计时器，不能伪称可唤醒。原生提醒注册独立应用身份，使用 Windows 通知中心与默认提示音，失败不得标记成功。

所有归档、画像和手账按账户保存，保存失败保留草稿。手账中明确区分用户记录与 AI 陪伴文字。

## 本轮功能

| 用户事项 | 实现与入口 |
| --- | --- |
| 1. 鲜明宠物个性 | 六种个性同时控制助手系统指令与本地互动语料。助手右上角可直接切换，也可在个人资料与设置中更改，按账户保存。 |
| 2. 有声桌面提醒 | Rust 后台检查任务提醒，注册 Windows 应用通知身份，通过原生 Toast 和默认提示音发送。成功后保存发送回执，失败可重试；切换账户和退出登录停止旧账户提醒。设置页提供有声测试提醒按钮。 |
| 3. 专注背景音乐 | 进入前及专注中可开关、调节音量。使用本机 WebAudio 生成无歌词的柔和纯音乐，休息、退出时淡出，无需下载录音。 |
| 4–5. 卡片外观 | 去除左右箭头，保留可手动滑动的隐藏滚动条；完整卡片缩短。提问后保持六张简略卡片同排，停止自动轮播。 |
| 6. AI 提醒 | 底部显示“以上内容均由 AI 生成，请谨慎参考。” |
| 7. 可选语音播报 | 每条助手回答可手动播放、停止并选择元气女生/活力男生；归档计划和周报也可播放。切换页面或账户中止播报，不自动朗读。 |
| 8. 今日计划/每日任务 | 任务清单按“全部 → 今日计划 → 每日任务 → 进行中…”排列。生成计划自动按日期归档，回答附入口提示。每日任务可查看定时任务配置和已生成结果。 |
| 9. 查看周报 | 日历&数据统计新增周报归档。保存生成时的真实统计快照，可重开查看历史对比、建议并播报。 |
| 10. 时间和批量选择 | 单个时间点按开始时间解释，结束默认加 30 分钟；没给时间时给出可修改的默认时段。有效历史时间可录入为逾期任务。全选/取消采用整批更新，不再只影响最后一项。真正的时间冲突仍需确认。 |
| 11. 用户画像/立即推荐 | 首次打开助手可现在填写或稍后填写；设置页可补填目标、兴趣、可用时间及节奏。推荐卡片直接按画像生成可勾选的任务，跳过画像时使用轻量通用建议。 |
| 12. 手账本&纪念日 | 保留原纪念日便利贴，新增手账本。树洞对话自动存页，支持照片、楷体手写纸张、翻页、编辑、贴纸拖动/双击移除、手绘/撤销。编辑草稿自动保存，安全退出时刷新草稿。 |
| 13. 导航名称 | 调整为任务清单、日历&数据统计、手账本&纪念日。 |
| 14. 定时任务位置和结果 | 配置卡片放到最新对话消息处并滚动到卡片顶部，使用宽版表单。结果支持安全的标题、列表、加粗和来源链接；执行指令要求只输出所需内容，避免多余的权限说明。 |

## 启动与数据

关闭旧版本时，请先从托盘安全退出，再双击项目根目录 `Start-MotiBuddy-AI.cmd`。启动器先检查本机 AI 服务，再启动 `MotiBuddy-Verify-companion.exe`，不要求在界面填写访问凭证。需要本机 Node.js 24 和已配置的私有服务文件；直接双击 EXE 不保证后台 AI 服务已经启动。

本次使用 `com.motibuddy.verify`，沿用此前验收版的数据位置。旧 EXE 保留，但不包含本轮功能。未自动关闭任何正在运行的用户窗口。

腾讯云使用 [TextToVoice 接口](https://cloud.tencent.com/document/product/1073/37995)，音色映射为云小朵 403000、懂事少年 603000，见[官方音色列表](https://cloud.tencent.com/document/product/1073/92668)。私有 Node 服务执行签名，前端仅提交文本和公开音色代号。播报按接口字数限制分段，支持取消、限流和错误脱敏。

当前是本机验收架构，私有配置不随 EXE 分发。未来面向其他用户发布时，应部署独立服务端和用户鉴权/配额，不能把供应商密钥或私有配置一起打包交付。

## 建议手动验收

1. 从启动器打开新版，先在个人资料与设置点击“发送有声桌面测试提醒”。确认 Windows 通知中心允许 MotiBuddy 通知，系统声音开启，勿扰模式关闭。创建提前 1 分钟提醒的任务，分别在窗口显示、最小化及隐藏到托盘时验证桌面弹窗与声音；同一提醒应只成功发送一次。
2. 在助手右上角切换傲娇、毒舌、幽默、高冷、软萌等个性，各发送一句话并点击右侧宠物，对比回答。设置变化应在重启及回到账户后保留。
3. 对一条回答分别选择元气女生、活力男生播放，验证实际音色、扬声器声音和停止按钮；切换页面应停止播放。云服务错误时应显示简短提示，不展示凭证。
4. 点击今日计划，再到任务清单 → 今日计划重新打开；点击每周复盘，再到日历&数据统计 → 周报打开。验证日期、完成记录和历史对比。
5. 文字或 Ctrl+V 图片输入“明天 9 点开会”，确认草稿为 9:00–9:30。生成多项后反复一键全选/取消，再修改其中一项、确认录入，检查任务栏和日历。过去的有效时间不应强制修改为未来。
6. 首次问卷选择稍后填写，再到设置补填；点击任务推荐应直接出现建议。提问后检查六张简略卡片同排且不再自动滑动。
7. 树洞发送文字和照片，到手账本查看；编辑、加贴纸、手绘，切换到个人资料再回来，以及安全退出重开，分别检查编辑草稿和已保存页面。
8. 设置 1 分钟专注/1 分钟休息，开关纯音乐并调整音量；检查开始播放、休息淡出、退出停止和时长记录。点击定时任务，确认表单位于最新对话处；定时执行后在每日任务查看结果和桌面通知。

## 验证范围与限制

自动化结果和本轮 EXE 哈希记录在 `COMPANION_BUILD.json`，实际 AI/TTS 接口测试记录在 `COMPANION_API_VERIFICATION.json`。浏览器界面回归使用合成账户、模型结果和存储故障注入；两种腾讯音色另外实际请求合成验证成功。Windows 原生接口已实际发送测试通知，但接口返回成功不等于已人工看到弹窗或听到声音，这两项仍需上述手动验收。

任务提醒由原生后台线程处理，主窗口隐藏时仍运行；定时 AI 任务需要应用进程及本机 AI 服务运行和网络连接。真正退出、电脑睡眠/关机时不执行；本轮没有安装 Windows 服务、开机自启或唤醒计划。Windows 勿扰、通知策略及音量可以抑制展示或声音。休眠恢复后的补发与长时间托盘运行仍需在目标机器验收。

模型个性及排版通过指令约束并有本地语料兜底，云模型输出仍可能有变化。手账原文与 AI 陪伴文字分开保存，避免把模型生成内容误认为用户的原始日记。

当前每日计划保留最近 90 个日期、周报保留最近 52 份。手账最多 200 页、单账户手账图片合计有容量限制；达到上限会阻止新增并保留旧页，不会自动删除旧日记。已有页面仍可编辑，未能保存时请保留草稿并整理旧页后重试。
