## 本轮实现

| 事项 | 当前行为 |
| --- | --- |
| 统一播报设置 | 助手右上角集中设置个性、元气女生/活力男生音色。小喇叭开启时自动朗读新回答，关闭立即停止并取消后续合成。对话消息下不再重复显示音色和播报控件。 |
| TTS 播放链路 | 点击发送、功能卡片或开启小喇叭时先启用 AudioContext，等待云端 MP3 后解码到音频缓冲区播放，避免在网络请求结束后才尝试启用播放器。显示播报状态，失败可重试。切页、切账户和关闭喇叭会中止播报。实际云合成及浏览器解码/开始/结束事件均已验证；扬声器听感仍需人工验收。 |
| 新对话与历史 | 支持新建、自动保存、搜索标题和聊天全文、打开历史并继续聊天。发送的用户消息在生成前先保存；已生成的回复、图片缩略图及已保存任务草稿随对话保存。切换前保存当前内容，失败保留页面。非当前对话可二次确认删除。 |
| 初始纪念案例 | 首次进入手账本&纪念日时，为空的手账和纪念日各添加一条案例。手账使用实际领养日期、宠物姓名和对应宠物照片；纪念日使用实际注册日期。已有内容不覆盖，删除或编辑后不反复补回案例。 |
| 四首专注音乐 | 可选择静心钢琴、水色梦境、轻甜柠檬、浮空之城。录音随应用打包，离线可播；保留作者、原曲名与 CC BY 4.0 授权链接。休息淡出、退出停止，保留音乐选择和音量。退出按钮改为无青色边框。 |
| 从任务进入专注 | 生成今日计划，或确认录入创建/推荐任务后，询问是否进入专注空间。确认后按第一项任务时长配置专注与休息轮次并开始；例如 20 分钟为一轮 20 分钟，40 分钟为两轮 20 分钟。初始记录保存成功后才进入。 |
| 日历与统计布局 | 日历行程置顶，摘要、专注统计和图表在中间，周报归档置底。统一边框、圆角、配色和间距，避免日历被纵向弹性布局压缩。 |
| 设置与头像 | 统一设置页外观，提供应用音量控制。编辑资料时上传 PNG/JPEG/WebP，缩小后保存并同步到主界面导航头像；图片处理完成前不允许保存。 |
| 天气与定位 | 导航栏原宠物状态区改为天气。可手动查找城市并选择，也可先同意定位再获取位置天气；拒绝后仍可手选城市。位置坐标粗化到小数点后两位，不发送给 AI。天气包含温度、天气状况、高低温、风速、来源和更新时间，约 30 分钟刷新，失败显示重试信息。 |
| 主界面顶栏 | 左上头像旁显示本地日期和时间，移除重复宠物等级及状态。系统顶栏只保留小尺寸原品牌图案与 MotiBuddy 名称。宠物对话气泡加入轻微背景模糊。 |
| 通知标题和 Logo | Windows Toast 固定标题为 MotiBuddy，任务名称和提醒内容放正文，并加入原应用品牌图案；注册通知应用名称与图标，继续使用系统提示音。 |
| 联网搜索与深度思考 | 输入区移除 Enter/Shift+Enter 提示，改为联网搜索和深度思考开关。搜索由私有服务调用 DeepSeek Search API，再把证据交给模型；思考使用实际 `thinking` 开关。不开启时不额外搜索。搜索失败明确报告，不伪造证据。 |
| 新闻逐事件介绍 | 模型按事件输出短标题和两句介绍，服务端检查每事件结构后排版。正文不放链接，链接只在来源区。保留真实来源、日期及证据约束，不能获取新闻时不编造内容。 |
| 更详细的画像 | 问卷在右侧宠物区域显示，可稍后填写；设置页也能编辑。增加可不透露的年龄段、身份职业、日常关注方向，可用时间改为约 15/30/60/120/240 分钟的选择题，保留目标、兴趣和偏好时段。 |

## 外部服务与资源

- 模型：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)与[搜索接口](https://api-docs.deepseek.com/zh-cn/guides/search/)。搜索直接使用固定的官方服务地址，供应商凭证始终在私有服务端。
- 天气：[Open-Meteo](https://open-meteo.com/)及其[城市检索接口](https://open-meteo.com/en/docs/geocoding-api)。当前为个人项目接入免费接口，公开商业发布前应按其[服务方案](https://open-meteo.com/en/pricing)选择合适套餐。
- 音乐：Kevin MacLeod，incompetech.com，四首录音均标注 CC BY 4.0，原始文件未改动。完整署名、来源和文件名见 `public/music/LICENSES.md`，应用内选择器也展示署名。
- 主界面与通知小图案从项目已有品牌图中提取，保留原角色，没有替换品牌设计。

## 数据与运行边界

对话按当前账户保存在原有原子业务存储中。最多 100 个对话，每个 200 条消息，历史总量约 8 MB；达到上限会拒绝新增并保留旧内容，不自动删除历史。模型每次使用近期对话和当前任务草稿，完整记录可在历史区搜索。图片历史保存缩略图，识别请求仍使用较高分辨率原图。

应用音量控制 TTS 与专注音乐；Windows 桌面通知的音量由系统控制。后台任务提醒仍要求应用在运行，可隐藏到托盘；真正退出、关机或睡眠时不执行。AI、TTS、搜索和天气需要各自网络服务；专注音乐不需要网络。

本机启动器需要 Node.js 24、项目依赖及忽略的私有服务配置。只分发 EXE 不会自动部署公网 AI 服务。当前没有把凭证加入前端、对话历史或可执行文件。

## 重点手动验收

1. 退出托盘中的旧版，使用根目录启动器打开新版。开启喇叭，分别选择两种音色发送短消息，确认实际出声；播放中关闭喇叭应立即停止，关闭后再发送不应自动播放。检查音量 0/35/100，并重启确认记忆。
2. 开启新对话，发送两段不同内容；搜索旧消息，点击结果续聊。切到设置再回来、重启后再打开历史，确认文本、图片和草稿恢复。保存失败时保留页面，不要直接丢弃。
3. 新账户注册和领养后进入手账本&纪念日，检查案例姓名、日期和照片；编辑或删除后重新进入，不应反复补回。
4. 选择一座城市检查天气。点击使用位置应先显示征询，选择暂不允许不应触发设备定位；同意后可能还会出现 Windows/WebView 的系统授权。定位不可用时手动选城市即可。
5. 生成今日计划或确认录入任务，确认进入专注，检查配置与任务时长对应。四首音乐逐一试听，检查休息、退出时停止和专注统计。
6. 在设置编辑资料并上传头像，等待处理后保存，回主界面检查头像、日期时间和小 Logo。打开日历&数据统计，确认日历在顶部且没有压缩成细线，周报在最底部。
7. 分别开关联网和深度思考发送问题，开启联网时检查来源。创建新闻定时任务，实际执行后核对每事件两句介绍、正文无链接、来源区有链接。
8. 设置中发送有声桌面测试通知，检查 MotiBuddy 标题、应用 Logo 和提示音；再验证任务提醒在最小化/托盘状态下能展示。

自动化与构建结果见 `WORKSPACE_V3_BUILD.json`；真实 API 结果见 `WORKSPACE_V3_API_VERIFICATION.json`。浏览器回归使用隔离合成账户及模型/天气结果，不读取真实业务 AppData；其播放事件不等于已人工听到扬声器声音。Windows 原生通知接口验收同样不能替代人工查看图标和声音。
