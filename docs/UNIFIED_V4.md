# 界面统一与交互修复（2026-10-17）

此版本完善助手历史、语音、初始手账、头像与天气功能。保留 `com.motibuddy.verify` 作为验收版数据目录标识，避免旧账户数据变成空白；Windows 通知单独使用稳定的 `MotiBuddy` 产品身份。

## 已实现

| 事项 | 行为 |
| --- | --- |
| 视觉统一 | 用共享样式统一黑色描边、白色底面、珊瑚色选中态、小偏移阴影和圆角。覆盖助手、统计、专注设置、手账、定时任务、资料设置，以及新天气和日历入口。全屏专注仍保留安静的纯白背景。 |
| 天气 | 导航栏天气卡片点击进入独立模块；显示当前温度、高低温、风速及未来 24 个小时的天气图标、温度和降水概率。预报使用城市当地时区。城市可以手选；定位仍需用户先同意，坐标不交给 AI。来源与更新时间可折叠。 |
| 日期与日历 | 导航栏时间仅显示时、分；点击打开月历，支持前后月份、回到今天、查看选中日期的任务和纪念事项。 |
| 助手工具 | 新对话、历史对话、个性与音色、播报开关放入同一工具组。个性与音色采用一致的上下排列选择框；切换音色后直接试听一小段，显式试听不会打开自动播报。麦克风和发送均为相邻的圆形图标按钮。 |
| 场景卡片 | 新对话恢复完整卡片并从右向左无缝循环；悬停暂停，系统要求减少动态效果时不自动滚动。提问后六张卡片缩小并停止自动滚动，仍可手动滚动。 |
| 对话区域 | 上下边缘增加羽化渐变。带来源标题或网址的资料默认收在可折叠区域；聊天、定时任务、已保存计划、周报和手账中的 AI 回信均复用同一格式组件。 |
| 陪伴语料 | 按六种个性分别重写点击、喂食、玩耍与思考语料，以自然心情和陪伴为主。宠物气泡使用白色 10% 不透明度，保留轻微模糊。 |
| 推荐多样性 | 画像仅作轻度参考，每批加入不同探索方向，并把最近推荐及已有任务标题交给模型避重；“换一批”直接生成新方案，仍须确认才会创建任务。模型语义上的完全不重复不能作为绝对保证。 |
| 情绪树洞 | 根据持续对话判断故事是否结束；未讲完时不提示入账。讲完或明确提出记录后显示保存确认，确认前不会写入手账；保存包含这一段多轮倾诉和回信，失败可重试，已有日记不覆盖。 |
| 通用问答 | 系统提示允许安全的一般知识、生活、技术及闲聊；不会仅因话题与任务无关而拒答，也不会把一般问题擅自变成任务。 |
| 专注研究 | 合并为一块，每次进入轮换不同研究提示，来源默认折叠。准确说明固定节奏对部分专注体验的研究结果和局限，不宣传未经证实的百分比。 |
| 专注音乐 | 修复两份设置校验冲突：旧校验会拒绝曲目字段，导致切歌无法保存。两处现在共享同一规则；曲目和音量即时响应、合并保存，失败保留选择并可重试，退出前刷新待保存设置。四首授权音乐随应用打包。 |
| 通知 | Windows 发送者使用 `MotiBuddy`，不再出现验收包 ID；正文不再重复插入品牌行。继续使用应用 Logo 与系统默认提示音。旧 ID 的历史通知由 Windows 自行保留，新通知使用新身份。 |
| 用词 | 任务清单里的“每日任务”统一改为“定时任务”。 |

## 研究与接口依据

- [Biwer 等，2023，原始研究](https://bpspsychub.onlinelibrary.wiley.com/doi/10.1111/bjep.12593)：87 名学生、单日研究；固定节奏组的休息前专注体验更好，但任务完成量未见显著组间差异。
- [Smits 等，2025，原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12292963/)：番茄法没有在所有指标上优于自主休息，支持保留可调节时长，不能据此承诺固定提升幅度。
- [Open-Meteo 官方小时预报说明](https://open-meteo.com/en/docs)：温度、天气代码、降水概率及城市时区。
- [Microsoft 应用通知身份说明](https://learn.microsoft.com/en-us/windows/win32/shell/appids)：通知身份独立于应用数据目录；未打包程序仍需适当的 Windows 注册。
- 音乐作者、曲名、原始来源和 CC BY 4.0 许可见 `public/music/LICENSES.md`，界面内也可展开查看。

## 人工验收

1. 先从托盘彻底退出旧版，再运行根目录 `Start-MotiBuddy-AI.cmd`，由启动器启动本机 AI 服务和新 EXE。直接打开 EXE 时，需要本机 AI 服务已经启动。
2. 点击时间查看月历；点击天气查看小时预报，手动切城市或明确同意定位。检查中文、英文及 1200×675、1600×900 窗口是否拥挤。
3. 助手开启新对话，观察卡片循环；发一条消息后检查紧凑卡片。切换音色试听、试用麦克风、打开和收起来源。
4. 连续“换一批”，检查推荐是否有新意。树洞先说未结束的事情，再补充结尾：结束前不能自动存入手账，点击确认后才出现完整倾诉。
5. 专注中逐个切换四首曲目并调整音量，退出后重新进入，确认选择保留且退出后停止播放。
6. 在资料设置中发送测试通知，再设置一个实际任务提醒并将应用留在托盘。人工确认 Windows 横幅显示 MotiBuddy 和 Logo、无重复品牌行、有提示音。原生自动验收确认系统接受调用，无法替代本人看见横幅和听见声音。完全退出进程后不会继续运行应用计时器。

密钥仅保留在被 Git 忽略的本机服务配置，不写入前端、EXE 或仓库。精确的自动测试与构建结果见同目录的 V4 验证文件。

自动验证：179 项 Node 业务测试、31 项 Rust 测试、1 项单独运行的真实 Windows 通知调用测试通过；整套浏览器回归与本轮专项回归均通过且无控制台异常。联网思考、逐条新闻、两款真实 TTS、通用问答、树洞结束判断、换批推荐和小时天气接口验证通过。浏览器音频验收检查了解码、开始与结束事件，并实际切换播放四首音乐；实际扬声器听感和 Windows 横幅最终外观仍按上述步骤人工确认。
