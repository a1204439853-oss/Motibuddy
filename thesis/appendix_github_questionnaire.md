# Appendix B: User Questionnaire

## B.1 Questionnaire Design

A user experience questionnaire was designed to evaluate the effectiveness of the MotiBuddy application. The questionnaire consisted of 29 items across six dimensions:

**Table B.1: Questionnaire Structure**

| Dimension | Items | Description |
|-----------|-------|-------------|
| Emotional Attachment | Q5-Q9 | User's emotional connection with the virtual pet |
| Self-Determination Theory | Q10-Q13 | Autonomy, competence, and relatedness needs |
| Gamification | Q14 | Effectiveness of game elements |
| Intelligent Features | Q15-Q17 | Voice input and desktop widget usability |
| Task Management | Q18-Q19 | Core task management functionality |
| Procrastination Reduction | Q20-Q24 | Impact on procrastination behavior |
| Overall Satisfaction | Q25-Q29 | General satisfaction and recommendation |

**Response Scale:** 5-point Likert scale (1 = Strongly Disagree, 5 = Strongly Agree)

## B.2 Questionnaire Items (English Translation)

**Demographic Information:**
1. What is your age?
2. What is your gender?
3. How long have you been using MotiBuddy?
4. How frequently do you use MotiBuddy?

**Emotional Attachment (Q5-Q9):**
5. I care about my virtual pet's health status when using MotiBuddy
6. I feel a sense of responsibility for my virtual pet while using the app
7. I would miss my virtual pet if I stopped using the application
8. The virtual pet makes using MotiBuddy more enjoyable
9. The virtual pet in MotiBuddy increases my frequency of using the application

**Self-Determination Theory (Q10-Q13):**
10. I feel a sense of choice and control over my tasks when using MotiBuddy
11. MotiBuddy helps me feel capable of managing tasks effectively
12. Through the virtual pet, I feel an emotional connection with this application
13. Using MotiBuddy is inherently satisfying, not just a means to complete tasks

**Gamification (Q14):**
14. Gamification elements (achievements, growth) motivate me to use the application

**Intelligent Features (Q15-Q17):**
15. The voice input feature makes adding tasks quick and convenient
16. Voice recognition accurately understands my task descriptions
17. The desktop widget makes it convenient to check tasks and pet status

**Task Management (Q18-Q19):**
18. Task management functions (add, edit, complete) are easy to use
19. Task sorting and priority features help me organize work orderly

**Procrastination Reduction (Q20-Q24):**
20. MotiBuddy helps me start tasks that I would typically procrastinate on
21. The virtual pet's reactions motivate me to complete tasks on time
22. Compared to other task management tools, I procrastinate less when using MotiBuddy
23. Worry about the pet getting "sick" prompts me to complete overdue tasks
24. MotiBuddy makes completing tasks feel more rewarding

**Overall Satisfaction (Q25-Q29):**
25. Overall, I am satisfied with MotiBuddy
26. I would recommend MotiBuddy to friends or colleagues
27. I plan to continue using MotiBuddy in the future
28. MotiBuddy is better than other task management applications I have used
29. The combination of virtual pet and task management is both innovative and practical
